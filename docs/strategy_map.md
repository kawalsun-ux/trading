# Strategy Map (template)

For each strategy idea, fill in:

- **Family**: trend / mean-reversion / breakout / arbitrage / market-making / ML
- **Source of edge**: behavioral, structural, risk premium, information, speed
- **Feasibility constraints**: data, latency, capacity, costs, regulation
- **Dominant failure modes**: regime change, crowding, cost cliff, overfitting
- **Version**: semver of the trading setup
- **Status**: research / paper / live / retired
